# Candidature Développeur IA agentique Simplon X Wild Code School

Ceci est un projet de visualisation de données, qui utilise le langage de programmation Pyhton.
Il utilise deux outils : [pandas](https://pandas.pydata.org/about/) et [plotly](https://plotly.com/python/).

## 🚀 Environnement et Configuration
Le projet a été développé et exécuté au sein d'un environnement virtuel **GitHub Codespaces**. La structure et l'arborescence technique s'appuient sur la configuration d'un **dépôt modèle (template)** crée ici : https://github.com/paufabregat/projet-devia-data-analyst-simplon/blob/main/README.md
